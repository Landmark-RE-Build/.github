# Landmark RE:Build

Landmark RE:Build is a community-driven, open source project that looks to preserve Landmark, a multiplayer, voxel-building game made by Daybreak Games Company, which was sunset in 2017.

## Purpose and Vision
The project’s primary goal is digital preservation - ensuring that Landmark remains accessible to future generations despite its closure by the publisher. By emulating the game’s original system, Landmark RE:Build allows players to experience the game in its intended environment, while also serving as a historical archive for gaming culture.
